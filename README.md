# TripSense

TripSense is an AI-powered tourism and hospitality platform that helps travelers decide **when to go, what to visit, and why**, while helping hotels forecast demand and make pricing decisions.

## Project Components

### 1. Demand Forecasting
Predict hotel occupancy using:
- Linear Regression
- Random Forest
- XGBoost

### 2. Hybrid Recommendation System
Personalized tourist-place recommendations using:
- TF-IDF content-based filtering
- Collaborative filtering
- Hybrid scoring

### 3. Best Dates
Calculate suitable travel dates using:
- Place comfort scores
- Indian holiday calendar
- Crowd/holiday penalty

### 4. Review Intelligence
Analyze hotel reviews using:
- Sentiment analysis
- Topic extraction

### 5. LLM + RAG
Generate grounded travel itineraries using verified places from the TripSense dataset.

### 6. Streamlit Application
The final application will contain:
- Trip Planner
- Demand Calendar
- Itinerary & Chat
- Map
- Hotel Dashboard
- Model Accuracy
- How It Works



## Dataset

The project uses tourism places, user interactions, hotel bookings, calendars and hotel reviews.
