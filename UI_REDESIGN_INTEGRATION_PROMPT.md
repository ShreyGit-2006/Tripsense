Tabs should behave like a connected two-mode product, not separate disconnected apps. Preserve selected form values if the user switches tabs. Use a persistent, obvious segmented control labelled “Trip” and “Hotel” near the top of the results page. Use an accessible active state and smooth motion; support keyboard and mobile interaction.
